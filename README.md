Beste lezer,

Voordat je begint met het draaien van de website kan het handig zijn om de dependencies op te halen. Dit doe je met:

"pip install uv"
"uv pip install -r requirements.txt"
"uv init"

Daarna kan je de website starten met "uv run python app.py"

Veel leesplezier!
